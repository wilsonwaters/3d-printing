# Hand Pump Wall Mount Bracket (v3)

Wall mount bracket for a Camec/Breha hand sink pump in a camp trailer.

## Design

- L-bracket with diagonal gusset brace for rigidity under pumping loads
- 32mm pump mounting hole in top shelf, 40mm from wall
- Two M5 wall mounting bolt holes (accessible from front)
- Bottom hose routing slot
- All corners rounded, edges chamfered
- PETG, designed for Bambu Lab X1C

## Files

- `hand-pump-bracket.scad` — parametric OpenSCAD model

## Printing

- Material: PETG (240C nozzle, 80C bed)
- Orientation: back plate flat on build plate (use `view = "print"` in the .scad file)
- 5 perimeters, 20% gyroid infill, no supports needed
