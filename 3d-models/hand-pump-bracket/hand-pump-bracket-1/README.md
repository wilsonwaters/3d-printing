# Hand Pump Wall Mount Bracket

3D-printable wall mount bracket for a **Breha hand pump** (camp trailer hand sink pump).

## Design

- Triangulated L-bracket with open front for pump body access
- Two side walls with diagonal bracing resist pumping forces
- Interior reinforcement ribs for additional stiffness
- Hose exits through left side wall with pass-through in left rib
- Chamfered shelf edges for hand safety
- M6 bolt holes for wall mounting (accessible from front)

## Specifications

| Parameter | Value |
|-----------|-------|
| Max envelope | 240mm H x 120mm W x 80mm D |
| Pump hole | 33mm (for 32mm mounting hole) |
| Pump hole center | 50mm from wall, centered on width |
| Wall bolts | 2x M6, centered, at 50mm from top and bottom |
| Material | PETG |
| Printer | Bambu Lab X1 Carbon |

## Print Orientation

Print on the **left side wall** (flat on build plate) for maximum strength under pumping loads.
