# Hand Pump Wall Mount Bracket v2

Wall mount bracket for a Breha hand pump (Camec SKU 005543) in a camp trailer.

## Design

Open-front box bracket (back + two sides + top shelf + bottom plate) with two internal diagonal gusset ribs. Single piece print on Bambu Lab X1C (256mm build height).

- **Material**: PETG
- **Dimensions**: 256mm H x 115mm W x 70mm D
- **Mounting**: 2x M6 bolts through back plate into wall
- **Tap hole**: 32.3mm in top shelf for pump drop-through
- **Hose hole**: 20mm in bottom plate
- **Top edges**: 2mm 45-degree chamfer

## Files

- `hand-pump-bracket-v2.scad` — parametric OpenSCAD model

## Printing

Single piece — F6 render, F7 export STL.
